# Firma legal home

Home corporativo para `ZULUAGA NAVARRO - ABOGADOS`, construido con HTML5, CSS3 y JavaScript puro.

## Estructura

```text
firma-legal-home/
|-- index.html
|-- css/
|   `-- styles.css
|-- js/
|   `-- main.js
|-- img/
|   |-- hero-legal.svg
|   |-- firm-office.svg
|   |-- lawyer-placeholder-1.svg
|   |-- lawyer-placeholder-2.svg
|   |-- lawyer-placeholder-3.svg
|   |-- article-labor.svg
|   |-- article-business.svg
|   |-- article-contract.svg
|   `-- README.md
`-- README.md
```

## Archivos

- `index.html`: estructura semantica del home con header, hero, confianza, areas, firma, beneficios, equipo, experiencia, principios, actualidad, contacto y footer legal.
- `css/styles.css`: estilos corporativos, variables de color, responsive, tarjetas, formularios, animaciones y estados hover.
- `js/main.js`: menu hamburguesa, header al hacer scroll, navegacion activa, animaciones y validacion visual del formulario.
- `img/`: imagenes SVG de ejemplo editables.

## Como ejecutar

Abre `index.html` directamente en tu navegador.

Tambien puedes abrir la carpeta en Visual Studio Code y ejecutar con la extension Live Server.
